# SSO Client Demo

Client App tối giản dùng HTML, CSS và JavaScript thuần để kiểm thử SSO flow.

## Chạy ứng dụng

```powershell
node server.js
```

Chọn port khác khi cần:

```powershell
node server.js --port=3001
```

Terminal sẽ hiển thị URL Client App và callback URL cần đăng ký với SSO Server.
